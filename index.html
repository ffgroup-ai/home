Tarlev Returns Automation

Internal document-processing automation for the Tarlev group of companies

What this application does

This application is an internal automation tool built for the Tarlev group of companies. It monitors a single, dedicated company mailbox (ffgroupai@gmail.com) for incoming customer product-return notices, extracts the return details from the attached documents, and automatically creates the corresponding accounting records in the company's internal 1C:Enterprise system. It then emails a processing summary back to internal accounting staff.

Specifically, the application:

  • Reads incoming emails and attachments (PDF, XLS/XLSX, DOCX) sent to ffgroupai@gmail.com.
  • Parses the attached return documents to extract contractor, organization, and product return line-item data.
  • Creates the matching "Product Return" and related tax-correction documents in the company's internal 1C:Enterprise accounting system.
  • Sends a summary email back to internal staff describing what was processed and what needs manual attention.
  • Marks each processed email as read, so staff can see at a glance which emails still need review.

Why this application requests access to Gmail data

The application requests the following Gmail permissions, all scoped to the single mailbox ffgroupai@gmail.com:

  • Read email messages and attachments — required to receive and parse the return-notice documents that customers/partners send to this mailbox.
  • Modify message state (mark as read) — required so staff can visually track, inside the same mailbox, which incoming return notices have already been processed by the automation.
  • Send email — required to deliver the automatically generated processing summary reports back to internal accounting staff.

This is strictly an internal business tool. It is not distributed to the public, does not act on behalf of any user other than the one dedicated company mailbox above, and does not use Gmail data for advertising or for training machine learning models.

Who operates this application

This application is developed and operated by the Tarlev group of companies for its own internal use. For questions, contact ffgroupai@gmail.com.
