Privacy Policy

Last updated: September 26, 2026

This Privacy Policy describes how the Tarlev Returns Automation Bot ("the Application", "we", "our") accesses and uses data through the Google account ffgroupai@gmail.com.

1. What this Application does

The Application is an internal automation tool used by Tarlev group of companies to process customer return documents (накладні на повернення) received by email. It is not a public-facing product and is not distributed to third parties.

The Application:

  • Reads incoming emails and attached files (PDF, XLS/XLSX, DOCX) sent to the connected Gmail inbox.
  • Extracts structured data (contractor, organization, product return details) from those attachments.
  • Creates corresponding accounting documents in an internal 1C:Enterprise system.
  • Sends summary emails back to internal staff reporting the result of this processing.
  • Marks processed emails as read.

2. Google user data accessed

The Application connects to the Gmail API using OAuth 2.0 and requests the following types of access for the single mailbox ffgroupai@gmail.com:

  • Read email messages and attachments (to extract return document data).
  • Modify message state (mark messages as read).
  • Send email messages (to deliver processing summary reports to internal staff).

3. How this data is used

Data obtained from Gmail is used solely to:

  • Parse business documents (product return notices) attached to emails.
  • Automatically create corresponding documents in the company's internal accounting system (1C:Enterprise).
  • Notify internal staff, by email, of the outcome of this processing.

No data obtained through the Gmail API is used for advertising, sold, or shared with any third party. Data is not used to train generative AI/ML models.

4. Data storage and retention

  • Email content and attachments are processed transiently by the internal workflow automation system (n8n, self-hosted) and the company's internal 1C:Enterprise database.
  • No email content is stored outside of the company's own internal, self-hosted infrastructure.
  • Processed emails remain in the connected Gmail mailbox (marked as read) subject to the mailbox's own retention settings.

5. Data sharing

We do not share, sell, or transfer any Google user data to third parties. Data extracted from emails is used exclusively within the company's own internal systems for the purpose described above.

6. Security

Access to the connected Gmail account and the internal automation system is restricted to authorized personnel of the company. OAuth credentials are stored securely within the self-hosted automation platform.

7. Google API Services User Data Policy

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Contact

For questions about this Privacy Policy, contact: ffgroupai@gmail.com.
